# Islamic App — Hadith Database

This repository distributes the Hadith database used by the Islamic app.

## Database

- **File:** `hadiths.db`
- **Format:** SQLite
- **Purpose:** Hadith collections, books, chapters, Hadith records, and Duas.

## Distribution

The database is intended to be downloaded by the app after installation, reducing the initial app download size.

The app verifies the downloaded database's SHA-256 checksum and SQLite integrity before activating it.
